# Playbot 0.6.1

Berichte verstehen. Module entdecken.

Veröffentlicht: 2026-09-11.

Wiederverwendbares Reporting, Datenbankzugriff und ein durchsuchbarer Einstieg in die öffentlichen Module.

## Neuerungen

- Reporting-Modul: PDF-Evidenz, Dashboard, vollständige Archivnavigation und Allure-Historie mit Fehlerkategorien.
- Datenbanken: DatabaseLibrary mit Oracle im Thin-Modus, MySQL und PostgreSQL.
- playbot discover: Modulübersicht, öffentliche Imports und JSON-Katalog ohne Laden optionaler Bibliotheken.
- VS Code und RobotCode: dokumentierter Einstieg in Vervollständigung, Keyword-Signaturen und Navigation.

## Übernahme in ein Projekt

reporting und database bei Bedarf aktivieren. Die Release-Version und den Image-Digest gemeinsam aktualisieren. Für die Editor-Unterstützung dieselbe Revision und Extras wie in CI verwenden.

## Grenzen

Das universelle PDF/JSON/XML-Vergleichsdashboard (#157) ist ein Konzept. Pact/Broker (#151) ist ein eigener Folgeausbau.
